# ens-mcp

A [Model Context Protocol](https://modelcontextprotocol.io) server that connects AI assistants to
ENS (Ethereum Name Service), published as `@thenamespace/ens-mcp`.

Version 0.1.0 is a rewrite in progress. See [CONTRIBUTING.md](CONTRIBUTING.md) to set up the
repository.
